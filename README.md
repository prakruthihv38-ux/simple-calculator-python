# Simple Calculator 🧮

A beginner-friendly calculator project built using Python.

## 📌 About the Project

This program allows the user to perform basic arithmetic operations by entering two numbers and selecting an operation.

## ✨ Features

* Addition ➕
* Subtraction ➖
* Multiplication ✖️
* Division ➗
* Handles division by zero
* Simple menu-based interface

## 🛠️ Technologies Used

* Python

## ▶️ How to Run

1. Download or clone this repository.
2. Open `calculator.py` in Python.
3. Run the program.
4. Enter two numbers.
5. Select an operation from the menu.

## 📚 Concepts Practiced

* Variables
* `input()` and `print()`
* Data types
* Arithmetic operators
* `if-elif-else`
* Error handling with conditions
* Basic problem solving
